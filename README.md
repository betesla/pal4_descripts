# editData

这是 PAL4 反编译出的脚本源码仓库。

## 使用说明

1. 需要先把游戏程序切换为 CS 模式（`launchCS.exe`）。
2. 将本项目脚本放置到游戏根目录下的 `gamedata/editData`。

CS 程序切换方法可参考：

- [仙剑4全剧情8万行游戏脚本发布（Bilibili）](https://www.bilibili.com/video/BV1oV9LBTEeD/?vd_source=606710064627f0dce2fbc778126fee92)

## 目录说明

- `script/`：脚本与工具目录
